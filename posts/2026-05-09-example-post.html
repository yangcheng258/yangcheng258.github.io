Example post: the build script works.

A short demo to verify the workflow is wired up. Delete this file (or replace its content) when you have a real post.

This file lives at posts/2026-05-09-example-post.html. Its <head> contains four <meta name="post:..."> tags that the build script reads.

When you ran python3 build.py, the script scanned this folder, found this post, and auto-generated a card on resources.html linking back to here — both in the grid view and inside the "News & notes" section in list view.

To add your own post: copy posts/_template-post.html, name it YYYY-MM-DD-some-slug.html, fill in the four meta tags + the body, and run python3 build.py. That's the whole loop.
